# Security and sensitive reports

This is a small, best-effort open-source project. There is no guaranteed support or response time.

For a potential vulnerability, use the repository's **Security → Report a vulnerability** private-reporting form. If that form is unavailable, open a minimal issue asking for a private contact route without publishing exploit details or personal data.

Do not post private images, credentials, personal paths, source grants, session snapshots or operation journals in a public issue. Share a minimal synthetic reproduction where possible. If a file operation fails, preserve local evidence and avoid repeated manual moves or deletes until the state is understood.

Only the latest main-branch source is considered for fixes. Published source is not a promise of signed binaries, a security audit or compatibility with arbitrary storage devices.
